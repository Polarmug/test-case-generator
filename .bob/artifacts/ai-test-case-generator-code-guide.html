AI Test-Case Generator — Code Guide

Key locations in the codebase and what the logic there actually does.

Location What it explains
backend / server.js
rateLimited() server.js · line 20 Sliding-window rate limiter keyed by client IP. Allows up to 10 requests per 15 minutes per visitor. IPs are tracked in a plain Map; old timestamp entries are pruned on every check, but the IP key itself is never evicted — a known slow memory leak on high-traffic deployments.
activeBobRunsconcurrency guard server.js · line 51 Caps simultaneous in-flight requests at MAX_CONCURRENT_BOB_RUNS (default 2). Note: the counter applies to all providers, not just Bob Shell — so a request routed to Groq or Gemini is still rejected with "Bob is busy" when the counter is full.
fallbackcatch block server.js · line 59 If every AI provider fails, the server returns fallback.json — a pre-saved example result — with fallback: true and a visible notice. The demo therefore never shows a raw 500 error; users always see a meaningful result.
trust proxyExpress setting server.js · line 33 Railway (the deployment platform) sits behind a reverse proxy. Without app.set('trust proxy', 1), req.ip would always be the proxy's internal IP, making the rate limiter useless — every visitor would share the same bucket.
backend / llm.js
SYSTEM_PROMPT llm.js · line 6 The instructions every provider receives. It hard-codes the allowed type values, requires steps to be an array, tells the model to tag each test case with the numbers of the criteria it covers, and demands bare JSON — no markdown fences. This tight spec is what makes the lenient normaliser below actually necessary.
env()helper llm.js · line 94 Treats both an unset variable and the your_… placeholder values from .env.example as "not configured". This means copying .env.example verbatim and forgetting to fill it in will silently skip those providers rather than sending garbage API keys.
BOB_WORKSPACE llm.js · line 113 Bob Shell is given an empty scratch folder as its workspace so it cannot read or write any project files. The same folder is reused across concurrent runs — not fully isolated, but safe because Bob runs with --disable-mcp and --disable-subagents.
callBob()key retry loop llm.js · line 135 Tries BOB_API_KEY first; if that fails for any reason except a timeout, it retries with BOB_API_KEY_2. A timeout is not retried because it means Bob itself is slow — a spare key wouldn't help and would just double the wait.
normalize() llm.js · line 356 Coerces whatever the model returned into the exact shape the frontend expects: renumbers IDs to TC-<storyId>-NN, maps fuzzy type labels ("positive", "boundary") to the canonical three values, converts string steps to an array, and recomputes coverage from the user's own criteria list rather than trusting whatever the model said.
tryProviders()provider chain llm.js · line 397 Iterates the configured providers in order (Bob → watsonx → Groq → Gemini). A provider is skipped not just on error but also if it returns zero test cases after normalisation — a technically successful but useless response still falls through to the next provider.
geminiModels()overload retry llm.js · line 284 GEMINI_MODEL can be a comma-separated list. Only HTTP 429 / 500 / 503 (overload / rate-limit) responses trigger a retry on the next model; all other errors fail fast to avoid wasting time on a definitely-broken key.
frontend / src / App.tsx
parseCriteriafrontend helper App.tsx · line 139 Mirrors the backend's parseCriteria: strips bullets (-, *, •) and numbering (1., 2)) from pasted text. Running the same logic client-side means the "N criteria detected" counter stays in sync with what the backend will actually receive.
visiblefilter map App.tsx · line 180 Maps each test case to { tc, index } before filtering by type. Keeping the original index means edit and delete operations always target the correct row in the full array, even when only a subset of rows is shown.
deleteRow()undo support App.tsx · line 243 Saves the removed test case and the pre-deletion coverage snapshot into lastDeleted. Undo restores both the row at its original position and the old coverage list in one setResult call. Only the most recent deletion can be undone — deleting a second row clears the undo buffer.
exportCSV()BOM byte App.tsx · line 265 The CSV blob is prefixed with a UTF-8 BOM (\uFEFF). Without it, Excel on Windows opens the file in the system's default ANSI encoding, which mangles characters like ₱ or accented letters in test data. The BOM signals UTF-8 to Excel without affecting any other tool.
API_URLdev vs prod App.tsx · line 57 In development the frontend (Vite, port 5173) and backend (Express, port 3001) run on different ports, so requests go to http://localhost:3001. In production the backend serves the built frontend from the same origin, so an empty string (same-origin relative URLs) is used instead. VITE_API_URL overrides both for custom deployments.
